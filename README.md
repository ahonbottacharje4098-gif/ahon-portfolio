# AHON — Personal Portfolio

A responsive personal portfolio website for AHON, a Computer Science student and aspiring developer.

## Built with
- HTML
- CSS
- JavaScript

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.

The site is a static website and does not require a build step.
